## 🛠️ How to Customize Your Details

Open `config.js` in any text editor and edit the following fields:

```javascript
developer: {
  name: "Your Name",               // e.g. "Rahul Sharma"
  title: "Full Stack Web Developer & AI Specialist",
  avatar: "your-photo-url-or-path.jpg",
  bio: "Your custom bio..."
},
links: {
  fiverr: "https://www.fiverr.com/your_username", // Your Fiverr profile/gig link
  whatsapp: "+919876543210",                       // Your WhatsApp number
  github: "https://github.com/yourusername",
  linkedin: "https://linkedin.com/in/yourusername"
}
```

## 🌐 Free 1-Click Deployment Guide

You can host this portfolio online for **100% FREE** in less than 2 minutes to get a live URL you can put on Fiverr:

### Option 1: Vercel (Recommended)
1. Go to [vercel.com](https://vercel.com) and sign in.
2. Drag and drop the `portfolio` folder directly into Vercel Dashboard.
3. Your site is live instantly with a free `.vercel.app` URL and free SSL!

### Option 2: Netlify Drop
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `portfolio` folder onto the page.
3. Your site is live immediately!

### Option 3: GitHub Pages
1. Push this folder to a GitHub repository.
2. Go to **Settings > Pages > Branch: main / root > Save**.
3. Your portfolio will be live at `https://username.github.io/repository-name`.
